# Compartir con la portada actual — 31/10/2026

El índice estático de Lupita Sensual conservaba la foto anterior mientras el perfil público ya tenía otra portada. El bloqueo al compartir evitaba enviar una imagen vieja, pero esperar en la misma pestaña no actualiza necesariamente el índice ni el modelo cargado.

Se regenera el índice, las fichas estáticas activas y la tarjeta de Tribunales desde el catálogo público actual. Al compartir se solicita una versión fresca del índice. Si la ficha cargada no coincide, se comprueba la foto actual de la ficha pública; se permite el enlace únicamente cuando el índice publicado coincide con esa foto. No se sustituyen originales ni se escriben fichas Firebase.

La foto vieja sigue bloqueada si la actualización pública aún está pendiente. La consulta adicional ocurre solo cuando hay discrepancia; el camino normal no agrega consultas. Se conservan campañas, fragmentos de la URL y métricas sin nuevas vistas virtuales.

Validación: tests de metadatos, resolución de enlaces, caché, pestaña anterior, cambio pendiente, perfil pausado, Analytics, contacto y accesibilidad. La versión del módulo se actualiza en la plantilla y todas las fichas activas.
